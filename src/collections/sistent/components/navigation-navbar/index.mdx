export const PermissionNavigationDemo = () => {
  const mockUserContext = {
    userName: "Demo User",
    orgName: "Layer5 Cloud",
    roleNames: ["Team Member"]
  };

  const samplePermissionKey = {
    id: "49a5b3a4-846c-4861-bf96-981cf26d70bc",
    function: "Manage Users",
    description: "Create and configure users.",
    category: "Identity & Access",
    subcategory: "Users"
  };

  const items = [
    {
      id: "users",
      title: "Manage Users",
      icon: <GroupIcon />,
      permissionKey: samplePermissionKey,
      permissionAction: "showShield",
      onClick: () => console.log("Manage Users clicked")
    }
  ];

  return (
    <PermissionProvider userHasPermission={() => false} userContext={mockUserContext}>
      <NavigationNavbar navigationItems={items} />
    </PermissionProvider>
  );
};

The **NavigationNavbar** component provides a structured, responsive vertical menu system ideal for application sidebars and settings panels. It supports a single level of collapsible nesting and integrates natively with Sistent's declarative authorization system to render unauthorized items as inert and display standard permission shields.

<a id="basic-navigation-navbar">
  <h2>Basic NavigationNavbar</h2>
</a>

A basic flat navigation list. Each item receives an icon, a title, and an `onClick` callback. Because `NavigationNavbar` relies entirely on external routing logic, developers must handle route matching and custom active styles (e.g., via customized `title` nodes) directly.

<a id="Usage">
  <h2>Usage</h2>
</a>

The `NavigationNavbar` component is highly versatile and accommodates several structural patterns:

- **Basic Navigation:** Flat menu lists for simple application routing.
- **Nested Navigation:** Single-level accordion menus for grouping related views.
- **Permission-Gated Navigation:** Items that automatically lock themselves and display a `PermissionShield` tooltip when users lack authorization.
- **Mobile-Only Navigation:** Items that can be dynamically hidden on desktop layouts using the `showOnWeb` property.

<a id="nested-navigation-navbar">
  <h2>Nested NavigationNavbar</h2>
</a>

Group related links under a collapsible parent item by providing a <code>subItems</code> array. The navbar natively manages accordion state to ensure only one nested section is open at a time. *Note: Nesting is strictly limited to one level deep.*

<a id="permission-gated-navigation-navbar">
  <h2>Permission-Gated NavigationNavbar</h2>
</a>

`NavigationNavbar` deeply integrates with Sistent's `PermissionProvider`. By supplying a <code>permissionKey</code> to any item, the component automatically blocks unauthorized clicks and prevents unauthorized parent items from expanding, rendering them completely inert while displaying a standard shield tooltip.
