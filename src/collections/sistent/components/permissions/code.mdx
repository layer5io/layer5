<h3>Base Component Permission Props</h3>

Components including `Button`, `IconButton`, `MenuItem`, `ListItem`, and `ListItemButton` accept the following props:

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `permissionKey` | `PermissionKeySpec` | `undefined` | Key or key set. When omitted, the component renders normally. |
| `permissionAction` | `'showShield' \| 'hide'` | `'showShield'` | When unauthorized, `'showShield'` attaches `PermissionShield` and `'hide'` renders `null`. |

<h3>PermissionShieldProps</h3>

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `permissionKey` | `PermissionKeySpec` | _required_ | Single `Key` or `{ anyOf: Key[] }` / `{ allOf: Key[] }` set. |
| `children` | `React.ReactNode` | _required_ | The affordance to guard. |
| `variant` | `'inline' \| 'badge'` | `'inline'` | Visual placement of the shield trigger icon. |

<h3>PermissionSessionContextProps</h3>

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `'tooltip' \| 'card'` | `'tooltip'` | Visual theme and sizing variant. |
| `permissionKey` | `PermissionKeySpec` | `undefined` | Self-resolving key or key set. |
| `displayedKeys` | `Key[]` | `undefined` | Pre-resolved array of keys to render. |
| `subtitle` | `string` | `undefined` | Custom requirement subtitle. |
| `categories` | `string[]` | `undefined` | Category chip labels. |
| `subcategories` | `string[]` | `undefined` | Subcategory chip labels. |

<h3>PermissionProviderProps</h3>

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `userHasPermission` | `(key: Key) => boolean` | _required_ | Authorization evaluator function. |
| `userContext` | `PermissionUserContext` | `undefined` | Session metadata: `{ userName, orgName, roleNames }`. |
| `children` | `React.ReactNode` | _required_ | Root application sub-tree. |
